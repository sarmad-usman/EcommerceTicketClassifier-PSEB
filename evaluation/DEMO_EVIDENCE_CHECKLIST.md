# Demo evidence checklist

Capture these screenshots during your own local run (the ZIP cannot truthfully contain screenshots of a server session that has not been launched):
1. Streamlit result for a valid fictional ticket, showing category, summary and mode.
2. Blank input validation message.
3. Backend unavailable message after stopping FastAPI.
4. FastAPI `/docs` page showing the `/analyze` route.
5. Terminal output for `pytest -q` and `python evaluation/run_evaluation.py`.

Add the screenshots to this folder before final LMS submission if the instructor requires visual evidence.
